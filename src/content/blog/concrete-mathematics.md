# Concrete Mathematics: 구체수학

## 1장 재귀적인 문제들

### 1. 하노이의 탑

*수학을 하나의 새로운 프로그래밍 언어로 생각하고 접근해보자*

수학적 귀납법도 함께 공부할 내용이다.

나는 항상 정의와 조건과 실질적 함수를 헷갈려했다. **명심**

`T(n) ≥ 2T(n-1) + 1`: 원판 n개를 옮기는 최소 이동 횟수의 **하한**을 나타낸다. 가장 큰 원판을 옮기기 전후로 작은 원판 n-1개를 옮겨야 하기 때문이다.

작은 원판들을 옮기고, 큰 원판을 옮기고, 다시 작은 원판들을 올리는 방법으로 이 하한을 달성할 수 있으므로 `T(0) = 0`, `T(n) = 2T(n-1) + 1`이라는 점화식을 얻는다. (수학에서는 점화식이다아!! 젠장!!)

### 2. 평면의 선들

1. n은 평면 위 직선의 개수. 선분이 아니라 양쪽으로 끝없이 뻗는 직선이다.
2. n = 0이면 영역은 1개다.
3. n = 1이면 최대 영역은 2개다.
4. n = 2이면 최대 영역은 4개다.
5. n = 3이면 최대 영역은 7개다.

평행한 두 직선이 없고 세 직선이 한 점에 모이지 않게 배치하면 n번째 직선이 영역을 n개 늘린다. 따라서 최대 영역 수는 `L(0) = 1`, `L(n) = L(n-1) + n`, 즉 `L(n) = 1 + n(n+1)/2`이다.
