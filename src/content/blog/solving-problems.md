> **2026-10-28 검토:** 2018년의 장애 조사 기록입니다. Xcode 버전·원본 이미지·재현 프로젝트가 남아 있지 않아 현재 환경에서의 재현이나 특정 버그의 수정 여부까지 확인한 글은 아닙니다.


# 그 동안의 문제들과 해결책

### 모 프로젝트에서 Xcode autocompletion 안되던 문제
[이슈]
- Xcode에서 개발자들이 autocompletion이 안되서 매우 불편하게 사용하고 있었음.

[관찰과 추정]
- 10메가를 넘는 이미지 파일에서 대량의 XML 메타데이터를 발견했고, 이미지를 제외하면 자동 완성이 다시 동작했음.
- 해당 리소스가 인덱싱에 영향을 주었다고 추정했다. 이미지 전체 크기와 헤더 크기를 별도로 측정한 기록이나 인덱서 로그는 없어, 정확한 내부 원인까지 확정할 수는 없음.

[해결]
- 처음에는 도무지 무슨 문제인지 몰랐다. 이런 문제가 처음이었기 때문에.
- 스택오버플로우등 가지가지 사이트를 검색하다. 특정 파일이 문제를 일으키는 것이 아닐까라는 생각을 떠올림
- resource의 타입별로 뭉텅이를 지워보기 시작
	- 소스, 이미지, 기타 등등을 하나씩 날려봄
	- 소스의 일부를 의심했으나 결국 테스트용도의 파일 하나만 남기고 지워봐도 autocompletion안됨
	- 이미지를 지웠을때 동작이 되기 시작함
	- 바로 이거다 라는 깨달음으로 이미지에 대한 삭제를 divide and conquer의 마음가짐으로 뭉텅이씩날려봄
	- 10메가를 넘는 이미지파일을 드디어 발견
	- 바이너리를 보니 헤더에 xml형식의 데이터가 대량으로 들어있는것을 발견
	- 더 생각하지 않고 해당 이미지를 새로 요구
	- 끗

## 비슷한 문제가 생기면 남길 정보

1. Xcode·macOS 버전과 오류가 나는 최소 프로젝트를 기록한다.
2. 원본을 보관한 별도 작업 사본에서 리소스 그룹을 나눠 제외하며 비교한다.
3. 문제 파일의 형식·전체 크기·메타데이터와 인덱싱 로그를 함께 확인한다.
4. 대체 파일을 넣은 뒤 자동 완성과 빌드를 다시 확인한다. 이 기록에는 대체 이미지 적용 후의 결과까지 남아 있지는 않다.
