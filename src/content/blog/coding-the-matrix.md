# Coding the Matrix

## Chapter 1

### 함수

#### 1.1 집합에 대한 용어와 표기법
- `1 ∈ {1, 2, 3, 4}`처럼 `∈`은 왼쪽 원소가 오른쪽 집합에 속한다는 뜻이다. 집합은 중괄호로 적는다.

#### 1.2 카테시안 곱(Cartesian product)
- 두 집합 A와 B의 카테시안 곱 `A × B`는 `a ∈ A`, `b ∈ B`인 모든 순서쌍 `(a, b)`의 집합이다.
- **유한 집합**이면 곱집합의 크기는 `|A × B| = |A| × |B|`이다. 각각의 집합 크기가 곱이라는 뜻은 아니다.
- 예를 들어 `A = {1, 2}`, `B = {x, y, z}`이면 `A × B`의 원소는 6개다.

#### 1.3 함수
**정의**
- 함수는 정의역(domain) D의 **모든 원소**에 공역(codomain) F의 원소를 **정확히 하나씩** 대응시키는 규칙이다. D와 F는 유한일 수도, 무한일 수도 있다.
- 함수의 그래프는 `(a, f(a))`라는 순서쌍들의 집합으로 나타낼 수 있다.

**표기**: `f: D → F`

실제로 출력되는 값들의 집합 `f(D)`는 치역(image)이며 공역 F의 부분집합이다. 원상(preimage)은 출력값이나 출력 집합에 대응하는 입력들의 집합을 뜻하므로, 정의역 자체를 가리키는 말로 혼용하지 않는다.

참고: 저자의 [The Function 강의 자료](https://codingthematrix.com/slides/The_Function.pdf), 집합·카테시안 곱·함수 절.
